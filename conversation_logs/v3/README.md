## 2. 核心變更點與記憶體優化 (Changelog)

### (1) 為什麼之前會出現「手機記憶體不足」？
- 現代 Android 手機相機畫素極高（動輒 4800 萬、5000 萬甚至 1 億畫素）。
- 舊版直接將整張幾千萬畫素的原始未壓縮點陣圖同時塞給兩張畫布 (Canvas) 解碼，瞬間在瀏覽器記憶體中吃掉超過 600MB ~ 1GB，超出手機瀏覽器單一分頁配額上限，導致手機系統強制報出「記憶體不足」。

### (2) v3 的解決方法（用意與功能）：
- **智慧尺寸安全約束 (MAX_IMAGE_DIMENSION = 1920px)**：
  - 將影像長邊上限約束在 1920 像素（約 Full HD / 200萬～300萬高畫素）。
  - 對於旅遊打卡、雲端備份、手機螢幕觀賞來說畫質極其細緻清晰，但記憶體消耗直接銳減 90% 以上（僅佔用約 8MB），完全杜絕手機記憶體耗盡問題！
- **記憶體即時釋放機制**：
  - 照片印章繪製完畢後，立即將 Canvas 暫存畫布清空重置，不佔用任何多餘的手機運行記憶體。

### (3) 相機黑畫面問題徹底解決：
- 進入網頁自動觸發 `startCamera()`，後置主鏡頭即時串流顯示於中央取景窗。
- 點擊紅色大快門按鈕，直接截取目前畫面，附帶快門白光閃爍動畫與觸感震動，免跳出、免等待！

## 3. 正確操作流程說明（小學生必看）

1. **開啟網頁**：在手機瀏覽器輸入網址：`https://kentislove.github.io/travel-footprint-camera/`。
2. **允許權限**：手機跳出提示「允許相機存取」與「允許位置存取」時，請務必點選 **「允許」**。
3. **看見畫面**：螢幕中央會立刻顯示真實世界的鏡頭取景畫面（若想自拍可點右上角「🔄 翻轉」）。
4. **拍照打卡**：按下螢幕下方正中間的 **「紅色大圓形快門」**。
5. **自動同步**：系統會以極快速度同時生成「打卡印章圖」與「純淨原圖」，並自動上傳至你的 Google 雲端硬碟！
