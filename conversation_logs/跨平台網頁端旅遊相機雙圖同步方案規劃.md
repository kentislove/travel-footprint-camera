# 跨平台網頁端 (Web App) 旅遊相機：雙圖保存與 Google 雲端同步架構規劃

---

## 1. 學生需求深度解析
- **跨平台通用性**：使用者同時擁有安卓 (Android) 與蘋果 (iOS/iPhone) 裝置，希望採用最不受手機作業系統限制的「網頁端 (Web App / PWA)」架構。
- **雙重照片保存 (A+B 都要)**：
  - **版本 A (視覺印章圖)**：在畫面印上清楚的繁體中文詳細地址、地標名稱、拍攝時間、經緯度座標。
  - **版本 B (純淨原圖)**：保留鏡頭最純粹的高畫質影像，不添加任何文字，僅嵌入數位定位資訊 (EXIF)。
- **核心架構**：方案三的精神——「前端拍照處理 + 後端/雲端搬運同步」。

---

## 2. 為什麼「網頁端應用 (Web App)」是最佳解法？
### (1) 用意
解決安卓手機與蘋果手機應用程式商店 (App Store / Google Play) 軟體不互通、界面不同、收費規則不同的困擾。

### (2) 功能與原理
現代智慧型手機的瀏覽器（蘋果的 Safari、安卓的 Chrome）都支援共通的開放網頁標準：
1. **相機呼叫能力 (MediaDevices API)**：可直接啟動手機的高畫質後置鏡頭。
2. **地理定位能力 (Geolocation API)**：可直接向手機作業系統請求當前 GPS 經緯度。
3. **繁體中文地址解析 (逆地理編碼 Reverse Geocoding)**：透過免費且開放的圖資服務（例如 OpenStreetMap 的 Nominatim 服務），將經緯度數值轉譯成台灣當地的完整門牌地址（例如：台北市信義區市府路1號）。
4. **畫布繪圖引擎 (HTML5 Canvas)**：在瀏覽器內部直接繪製文字浮水印，同時輸出「原圖」與「蓋章圖」。
5. **離線暫存能力 (IndexedDB / LocalStorage)**：即使在深山收訊不良時，拍下來的照片先存放在手機瀏覽器內部，絕不漏拍或遺失。

### (3) 為什麼這樣做？
只要透過瀏覽器打開同一個網址，然後點選「加到主畫面」，手機畫面上就會出現一個像一般 App 一樣的圖示，點開就是全螢幕專屬相機，免安裝、免跨系統適配，雙平台體驗完全一致！

## 3. 「A+B 雙圖保存」的運作機制設計

當小學生在網頁相機上按下「拍照」快門的那一秒，系統內部會執行以下連續動作：

```
[使用者按下拍照快門]
         │
         ├──► 1. 抓取手機當前精確 GPS 經緯度、海拔與精準時間
         ├──► 2. 線上查詢目前位置的繁體中文門牌地址
         │
         ├──► 3. 產出【版本 B：純淨原圖】
         │       └─ 保持原始最高解析度，不畫任何文字
         │
         ├──► 4. 產出【版本 A：印章打卡圖】
         │       └─ 利用畫布在照片角落畫上沉穩的半透明黑底，
         │          整齊排版繁體中文地址、時間、經緯度與旅行標題
         │
         └──► 5. 同步至 Google 雲端硬碟 (Google Drive)
                 ├─ 資料夾 1：/旅遊紀錄/2026/純淨原圖/
                 └─ 資料夾 2：/旅遊紀錄/2026/打卡印章圖/
```

## 4. Google 雲端硬碟連動的兩種實施路徑（供學生挑選）

要讓網頁端直接將雙版本照片傳入使用者的 Google 雲端硬碟，有以下兩種實現方式：

### 路徑一：Google 官方免費指令碼串接 (Google Apps Script - 輕量極簡推薦)
- **用意**：完全免費、不需要租用雲端伺服器，直接在小學生自己的 Google 帳號裡建立一個專屬接收窗口。
- **功能**：
  1. 老師幫你寫一段簡單的 Google Apps Script (GAS) 接收程式碼，貼到你的 Google 雲端後台。
  2. 網頁拍完雙版本照片後，直接打包傳送給這個專屬接收窗口。
  3. 接收窗口會自動在你的 Google 雲端硬碟建立「旅遊相簿」資料夾，將原圖與印章圖分門別類存好。
- **優勢**：安全、隱私完全操操在自己手中，免付伺服器月租費，蘋果與安卓均完美支援。

### 路徑二：純前端 Google 官方授權登入 (Google Drive API Client)
- **用意**：網頁端第一次使用時，跳出「登入 Google 帳號並授權存取雲端硬碟」的按鈕。
- **功能**：由網頁直接透過 Google 官方的 API 介面將檔案上傳到指定資料夾。
- **注意事項**：需要前往 Google Cloud 平台申請一組免費的用戶端金鑰 (Client ID)。

## 5. 後續實作步驟建議
1. 老師可以直接為你開發這套【專屬旅遊雙圖定位相機網頁 (HTML+JS)】。
2. 配合 Google Apps Script 建立專屬自動上傳接口。
3. 產生後的單一網頁檔案可以放在電腦本地測試，也可以免費部署到網路上（例如 GitHub Pages 或 Vercel），讓你的兩台手機隨時掃描 QR Code 就能開拍！
