## 2. 核心技術修復點 (Changelog)

### (1) 為什麼網頁下方之前會被狀態列擋住？
- 在手機行動端瀏覽器中，傳統的 `height: 100vh` 會把被手機底部虛擬按鍵、手勢小白條遮蔽的區域也算進去，導致底部的拍照快門按鈕沉入螢幕底下被遮住。
- **v4 解決之道**：
  - 全面採用現代行動端標準 `height: 100dvh` (動態視窗高度)。
  - 底部操作列明確向上墊高，加入 `padding-bottom: calc(24px + env(safe-area-inset-bottom, 20px))`，保證大快門完整浮在手機導航條與狀態列上方，看得清清楚楚、按得順順暢暢！

### (2) 為什麼手機鏡頭之前無法成像？
- 在部分 Android 手機上，舊版直接寫死請求特定的高解析度或在無手勢下自動播放，觸發了手機硬體驅動的限制 (`OverconstrainedError`) 或被瀏覽器的自動播放安全策略攔截，導致相機畫面呈現黑屏。
- **v4 解決之道**：
  - 導入「三階段漸進相容性請求」：
    1. 階段一：寬鬆理想模式（由手機驅動挑選原生最順暢比例）。
    2. 階段二：精確方向模式。
    3. 階段三：基本視訊模式（保底相容所有安卓與蘋果裝置）。
  - 在觀景窗中央加入醒目的【🚀 點我啟動相機畫面】大按鈕，只要手指輕輕一碰，立刻滿足瀏覽器的「使用者手勢安全授權」，鏡頭瞬間亮起、順利成像！

## 3. 手機操作檢查指引

1. 打開網址：`https://kentislove.github.io/travel-footprint-camera/`。
2. 看到頂部標題顯示綠色「**v4**」標籤，代表手機已成功讀取到最新修復版。
3. 若中央出現「🚀 點我啟動相機畫面」大按鈕，點一下並允許相機權限，畫面中央即可即時看見鏡頭影像！
4. 底部紅色大快門按鈕已向上拉高，完全不會被手機下方的狀態列或小白條擋住！
