## 2. 核心變更點與架構解說 (Changelog)

### (1) 為什麼之前拍照後要等 5~10 秒？
- 舊版把「拍照」和「網路傳輸到 Google 雲端」綁在同一個動作中。
- 當照片在傳送給 Google Apps Script 時，畫面跳出全螢幕遮罩等待伺服器回應，導致在網路不佳或伺服器處理時，小學生必須站在原地乾等，非常影響旅遊拍照的興致。

### (2) v5 的秒拍新架構（用意與功能）：
- **前後台完全分離**：
  - **前台（快門與觀景窗）**：按下快門 ➔ 閃光動畫 ➔ 0.1 秒內在背景產生「打卡印章圖」與「純淨原圖」➔ 立即把任務丟進背景排隊區 ➔ 觀景窗**毫不停頓**，立即可以繼續拍下一張！
  - **後台（背景排程上傳工兵）**：系統在背景依序消化排隊中的照片，一張一張自動送進 Google 雲端硬碟，即使遇到網路短暫不穩，也會自動稍後重試，完全不會跳出彈窗打擾小學生拍照！
- **頂部微型狀態徽章**：
  - 頂部導航列多了一個小巧的「☁️ 雲端狀態徽章」：
    - `☁️ 全部已同步`（亮綠色）：代表所有拍過的照片都已安全送達 Google 雲端硬碟！
    - `☁️ 同步中 (剩餘 2 張)...`（微動態）：代表小學生拍得太快，背景工兵正在默默幫你傳送第 2 張照片，完全不擋鏡頭！
- **左下角相片縮圖按鈕**：
  - 像手機內建相機一樣，每拍完一張，左下角的縮圖框立刻更新為最新拍好的照片。
  - 點一下縮圖框，才打開大圖檢視，並提供「💾 存入手機相簿」按鈕！

## 3. 手機操作檢查指引

1. 打開網址：`https://kentislove.github.io/travel-footprint-camera/`。
2. 重新整理後，確認頂部標題顯示綠色的 **「v5 秒拍」** 標籤。
3. 點擊啟動相機後，嘗試**連續點擊紅色快門**！
4. 體驗快門像機關槍一樣隨點隨拍、完全零等待的流暢手感！
5. 注意看頂部的小徽章，會自動顯示 `☁️ 同步中...` ➔ 幾秒後自動變成 `☁️ 全部已同步`！
