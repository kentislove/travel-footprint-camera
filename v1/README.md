# 旅遊足跡相機 (v1) - 版本說明與操作教學文件

---

## 1. 版本基本資訊
- **版本號**：v1
- **建立日期**：2026 年 11 月 26 日
- **作者/角色**：AI 老師（為小學生量身打造）
- **核心定位**：跨平台（蘋果 iOS 與安卓 Android 皆相容）的旅遊打卡專用網頁端相機 (Web App)，支援「一次快門產出雙版本照片（印章圖 + 純淨原圖）」並自動同步到 Google 雲端硬碟。

---

## 2. 本版本核心功能與變更點
1. **跨平台網頁端架構**：
   - 採用標準網頁技術 (HTML5 + CSS3 + JavaScript)，不論是在 iPhone (Safari) 還是 Android (Chrome) 都可以完美運作。
   - 支援「加到主畫面」功能，點擊桌面圖示直接以全螢幕 App 方式啟動。
2. **衛星定位與中文地址即時解析**：
   - 即時追蹤 GPS 衛星定位座標（經度、緯度、精準度公尺數）。
   - 串接開放街圖 (Nominatim) 逆地理編碼服務，全自動將數字座標轉譯為台灣當地的繁體中文門牌地址（如：台北市信義區...）。
3. **雙版本照片 (A + B) 同時生成**：
   - **版本 B（純淨原圖）**：維持鏡頭拍攝最高解析度原圖，不破壞風景構圖。
   - **版本 A（打卡印章圖）**：自適應在照片底部繪製半透明黑底印章卡，印上【旅行主題、繁體中文地址、拍攝時間、衛星經緯度】。
4. **雲端與離線雙重保障**：
   - 支援將照片一鍵存回手機相簿。
   - 串接專屬的 Google Apps Script (GAS) 接收小幫手，拍完自動在 Google 雲端硬碟分類建立資料夾，並附帶生成一份當日旅遊足跡的 CSV 試算表（包含 Google 地圖一鍵導航連結）。

## 3. 檔案結構清單
- `v1/index.html`：網頁相機使用者介面（包含快門按鈕、預覽分頁、設定視窗）。

## 4. 手把手教學：如何啟用你的 Google 雲端自動同步？

小學生請跟著老師以下 5 個簡單步驟操作，只需要做一次，以後就能終身使用囉！

### 步驟 1：打開 Google 雲端硬碟的指令碼編輯器
1. 在電腦瀏覽器打開 [Google Apps Script 官網](https://script.google.com/) 並登入你的 Google 帳號。
2. 點擊左上角的 **「新專案」**（藍色加號按鈕）。

### 步驟 2：貼上接收小幫手程式碼
1. 將專案編輯器中原本的代碼清空。
2. 打開 `v1/google_drive_receiver.gs` 檔案，把裡面的全部內容複製下來，完整貼到 Google 編輯器中。
3. 點擊上方的磁碟片圖示（或按鍵盤儲存快速鍵）儲存專案。

### 步驟 3：部署發布為網頁應用程式
1. 點擊右上角藍色的 **「部署」** 按鈕，選擇 **「新增部署作業」**。
2. 齒輪圖示選擇 **「網頁應用程式」**。
3. 設定選項說明：
   - **說明**：輸入「旅遊相機接收器」。
   - **執行身分**：選擇「我 (你的電子郵件)」。
   - **誰可以存取**：選擇「任何人」（重要！這樣手機網頁端才能將照片傳給它）。
4. 點擊 **「部署」**。

### 步驟 4：授權存取
1. 第一次部屬時，Google 會跳出「核准存取權」的確認視窗。
2. 點擊你的帳號 ➔ 點選「進階 (Advanced)」 ➔ 點選「前往專案 (Go to ... Safe)」。
3. 點擊「允許」授予雲端硬碟寫入權限。

### 步驟 5：複製網址並填入相機設定
1. 部署完成後，畫面會產生一串「網頁應用程式網址」（開頭是 `https://script.google.com/macros/s/.../exec`）。
2. 將這串網址複製起來。
3. 打開我們的旅遊相機網頁，點擊右上角的 **「⚙️ 設定」**，把網址貼上並按下「儲存設定」！

大功告成！之後每一次拍完照片，系統就會自動幫你把「原圖」和「印章圖」整齊存入你的 Google 雲端硬碟中囉！
